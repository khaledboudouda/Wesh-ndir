مشروع وش ندير؟ - نسخة أولية PWA

الملفات:
- index.html: الواجهة والتفاعل الأولي.
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت.
- sw.js: التخزين المؤقت للعمل الأساسي دون اتصال بعد أول تحميل.

التشغيل:
1) ارفع المجلد إلى استضافة تدعم HTTPS (مثل GitHub Pages أو Netlify).
2) افتح رابط الموقع على Android من Chrome.
3) اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق" إذا ظهر الخيار.

مهم:
هذه نسخة واجهة وتجربة أولية وليست خدمة إنتاجية. الردود تجريبية وليست متصلة بنموذج ذكاء اصطناعي أو مصادر حكومية مباشرة. لا توجد حسابات أو قاعدة بيانات سحابية أو نظام تنبيهات بعد. يلزم تطوير خلفية آمنة، ربط مصادر رسمية، اختبارات، وسياسة خصوصية قبل الإطلاق العام.
